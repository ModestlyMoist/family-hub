# The Family Hub

A mobile-first family dashboard for calendar events, custody, payments, weekly staples, meal planning, household tasks, and Las Vegas / Flagstaff weather.

## Try it locally
Open `index.html` with a local web server. The sample PIN is **2468**. Sample data is included and saved in browser storage.

## GitHub Pages
Upload this folder to a GitHub repository, then enable Pages from the repository's Settings → Pages. See `SETUP.md` for the no-code-ish checklist and Supabase sync architecture.

## Privacy note
Do not put private family data directly in this public repository. The included sample data is fictional. For real synced family data, enable Supabase using `SETUP.md` and keep secrets in Supabase, not GitHub.
